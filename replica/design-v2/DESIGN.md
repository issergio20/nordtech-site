# Дизайн-система «НОРД Тёмный» (вариант 2)

Создана с нуля 2026-11-10 вместо варианта 2 на UI kit оригинала. Вариант 1 (копия nordtech.su) не изменён.

- Стиль: премиальный тёмный — глубокий графит, крупные фото техники, тонкие линии, мягкие скругления, синий НОРД как акцент.
- Код: `site/src-v2/` (шаблоны, `scss/`, `js/app.js`). Данные и фото общие с вариантом 1: `site/src/_data`, `site/src/assets`.
- Сборка: `VARIANT=2` (локально `npm run dev:v2` → http://localhost:8081, витрина компонентов — `/ui-kit/`).
- Без CSS оригинала, без Swiper. Fancybox — только полноэкранное фото товара и сертификаты.

- С главной убран блок «Официальный дилер» (решение заказчика). Сертификаты остались в «О компании».

- FAQ в «О компании»: на оригинале три одинаковых вопроса-заглушки — оставлен один.
- Ссылки и названия для сценариев (заявка, лизинг, поиск, контакты) совпадают с вариантом 1 — общие e2e-тесты проходят на обоих.

## Правки по замечаниям заказчика (2026-11-10, вечер)

1. Текст под заголовком первого экрана — 16 → 20 px вместо 18 → 26.
2. Движение: плавный переход между страницами (View Transitions, шапка стоит на месте), заголовки секций и карточки появляются при прокрутке, у плиток — синяя заливка и проявление подразделов по очереди.
3. Отступы: токены `--pad` (карточки и плитки) и `--pad-lg` (панели); между секциями одного фона — один `--section`, на границе фонов — у каждой свой.
4. Каталог — 3 × 2 (2 на планшете, 1 на телефоне): фото, заголовок (Unbounded 500, 18 → 26 px), круг со стрелкой; при наведении — синий фон и список подразделов.
5. «Как мы работаем» — общий ритм секций, без прилипания к предыдущему блоку.
6. «Сервисные услуги» — на всю ширину (4 / 2 / 1 колонки), заголовки карточек обычной жирности.
7. Лизинг: слева заголовок, текст, шаги 01–04 (основной размер) и кнопки; справа столбиком «от 10% / 12–60 мес / 2 часа».
8. «Подбор за 2 часа»: заголовок слева, справа текст и кнопки в одну линию.
9. Подвал: без большого «НОРД», верх и низ по сетке из 4 колонок, логотип ВостокВеб с подписью «Разработка сайта — ВостокВеб».
