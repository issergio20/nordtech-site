# Полный анализ варианта 2 (ui-ux-pro-max)

Дата: 2026-11-10. Ограничение заказчика: UI kit НОРД не меняется — правим только подачу (раскладка, размеры, порядок, удобство).
Методика: скрипт `site/scripts/audit.mjs` — 15 страниц × 390 и 1440 px (зоны нажатия, размеры текста, длина строк, заголовки, картинки без размеров, CLS, фиксированные элементы, имена контролов) + просмотр экранов + запросы к базе скилла. Сырые данные: `audit-v2.json`.

## Что подтвердила база ui-ux-pro-max

| запрос (`--domain ux`) | правило | важность |
| --- | --- | --- |
| touch target size | **веб: 24×24 CSS px** (WCAG 2.5.8) — обязательно; 44pt/48dp — для нативных приложений, на сайте как рекомендация | High |
| horizontal scroll carousel mobile | контент помещается по ширине экрана | High |
| lazy load images dimension | ленивая загрузка ниже экрана + размеры/формат | High / Medium |
| floating label (из прошлого анализа) | подпись видна всегда | High |
| primary action single cta | **совпадения нет** — использовано правило `primary-action` из чек-листа скилла (одно главное действие на экран) | — |

### В порядке

- Горизонтальной прокрутки нет ни на одной странице (обе ширины).
- Один H1 на странице, у всех контролов есть имена, контраст AA (axe).
- CLS при загрузке без прокрутки: 0–0.011.
- Фиксированные элементы: только шапка (54 px) и нижняя панель (62 px), контент под ними не прячется.

## Итог после переделки

Все пункты B1–B6 и M1–M7 внесены. Аудит `site/scripts/audit.mjs` (15 страниц, 390 и 1440 px): было `audit-v2.json`, стало `audit-v2-after.json`.

| Показатель | Десктоп, до → после | Телефон, до → после |
|---|---|---|
| Зоны нажатия меньше 24 px | 19 → 1 | 4 → 1 |
| Картинки без размеров | 26 → 0 | 17 → 0 |
| Текст мельче 12 px | 0 → 0 | 51 → 15 |
| Основной текст мельче 16 px | 0 → 0 | 111 → 74 |
| Горизонтальная прокрутка | 0 → 0 | 0 → 0 |

Остатки:
- зона меньше 24 px — кнопки-точки карты в «Контактах» (16×6), они скрыты от пользователя и дублируются списком филиалов;
- мелкий текст на телефоне — подписи нижней панели (12 px), допустимое исключение для таб-бара;
- пропуски уровней заголовков в «Контактах» и «Политике» — ложные: аудит не учитывает визуально скрытые `h2`;
- CLS выше 0,1 на карточках и в поиске — шум последовательного прогона: при отдельной проверке смещение 0.

Тесты: вариант 1 — 94 пройдено; вариант 2 — 106 пройдено, 2 нестабильных при параллельном прогоне (контраст и S06), при повторе 9 из 9 зелёные. Липкая кнопка на карточке переведена с IntersectionObserver на проверку при прокрутке: наблюдатель не срабатывал при резком переходе.

## Движение и адаптивная типографика (после переделки)

**Шкала шрифтов.** Одна плавная шкала `clamp(rem + vw)` в `v2.scss` (`--fs-display … --fs-small`): текст растёт от 360 до 1920 px и учитывает размер шрифта в браузере. Замер (360 / 1024 / 1920 px):

| Уровень | Было | Стало |
|---|---|---|
| Заголовок первого экрана | 32 / 35 / 56 | 37 / 54 / 72 |
| Заголовки секций | 24–28 / 24–28 / 36–44 | 28 / 38 / 48 |
| Заголовки карточек | 16–24 / 20–24 / 32–42 | 20 / 26 / 32 |
| Основной текст | 14–16 / **12–14** / 16 | 16 / 17 / 18 |

**Первый экран.** На всю высоту (`100svh`) на любом устройстве; на телефоне текст и кнопки внизу, над нижней панелью. Затемнение поверх видео для читаемости. При загрузке видео мягко приближается, строки поднимаются по очереди (0,9 с, ease-out). При прокрутке видео уходит медленнее текста, текст гаснет (scroll-driven animations, где браузер их поддерживает).

**Блоки.** Появляются при прокрутке: подъём на 28 px и проявление, карточки — «лесенкой» по 70 мс (не больше 6 шагов). Видимое при загрузке не скрывается. После появления атрибут снимается, и у карточек возвращаются эффекты наведения kit.

**Ограничения.** Только `translate`, `scale`, `opacity`. При «Уменьшить движение» анимаций нет, видео не запускается. Тесты, аудит и скриншоты идут в этом режиме; отдельный тест V2-11 проверяет появление с включённым движением.
