# Вариант 2 — улучшенный внешний вид на UI kit НОРД

Решение заказчика 2026-11-10: **UI kit остаётся как в варианте 1** (CSS nordtech.su, BEM-классы, палитра с правками AA, Onest, спрайт, Swiper/Fancybox).
Вариант 2 меняет только подачу: раскладку, размеры, плотность, удобство форм и мобильного — и добавляет недостающие блоки из тех же компонентов.
Основа — проблемы из `ANALYSIS.md` (чек-лист ui-ux-pro-max). Палитра и шрифт из ранней версии этого файла (Sofia Sans, янтарный акцент) **отменены**.

Сборка: `VARIANT=2` (стили `site/src/scss/v2.scss` поверх kit + условные блоки в шаблонах). Без флага собирается вариант 1 без изменений.
Публикация: вариант 1 — `/nordtech-site/`, вариант 2 — `/nordtech-site/v2/`.

## Что меняем

| # | проблема (ANALYSIS.md) | вариант 2 |
| --- | --- | --- |
| L1 | Секции главной по 100vh, пустоты | секции по высоте контента, отступы 96 / 64 px; первый экран — до 760 px |
| L2 | Контент прижат вправо под боковую навигацию | боковая навигация убрана, контейнер по центру, максимум 1320 px |
| T1 | Заголовки 46–60 px, 900 | секции 28–44 px, название товара 24–36 px; вес и прописные — как в kit |
| A3 | Кнопки 12 px | 14–16 px, высота ≥ 48 px |
| A4 | «Используйте клавиатуру» под каждым слайдером | убрано (стрелки и клавиатура работают) |
| A1 | Партнёры прокручиваются сами | статичная сетка логотипов |
| A2, F1 | Подпись внутри поля, нет обязательности | подпись над полем всегда, звёздочка у обязательных |
| L3 | На мобильном скрыты «Каталог» и лизинг | показаны |
| — | На мобильном карточка товара: кнопка далеко | липкая полоса «Узнать стоимость» над нижней панелью |
| — | Карточки без характеристик пустые | «Характеристики — по запросу», карточки одной высоты |
| N1 | «Каталог» в шапке ведёт себя по-разному | всегда `/katalog/` |
| Доверие | сертификаты спрятаны в «О компании» | блок «Официальный дилер» с сертификатами на главной |
| Мессенджер | Telegram — иконка в шапке | «Написать в Telegram» в окне заявки |

Не меняем: цвета, шрифт, иконки, формы кнопок и карточек, порядок секций, тексты.

Дополнительно по ходу сборки:
- плавающая кнопка «Логистика» скрыта — перекрывала ссылки при прокрутке (пункт есть в меню «Услуги»);
- якоря не прячутся под фиксированной шапкой (`scroll-margin-top`);
- липкая кнопка на карточке товара появляется только после прокрутки ниже основных кнопок и стоит над нижней панелью.
