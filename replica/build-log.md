# Журнал сборки nordtech.su

Решение (2026-11-10): локально нет PHP, MySQL и Docker, поэтому сначала делаем **статичную вёрстку** на Eleventy 3 + SCSS (`site/`), а натяжку на MODX — отдельным шагом на staging.
Шаблоны Nunjucks разбиты так, чтобы 1 файл = 1 чанк Fenom: `_includes/partials/*` → чанки шапки, подвала, окна заявки; `_includes/ui/ui.njk` (макросы) → `chunks/ui/*.tpl`; `_data/*` → поля ресурсов, miniShop2 и `modx_nord_branches`.
Запуск: `npm --prefix site run dev` → http://localhost:8080. Слой заявок `site/src/js/lead-api.js` работает как заглушка; в MODX достаточно задать `window.NORD_LEAD_ENDPOINT`, код экранов не меняется.

## Отклонения от правил и долги

- **Тексты.** Это сайт самого клиента, поэтому названия, характеристики и условия лизинга перенесены (с правкой ошибок), а маркетинговые формулировки переписаны. Всё в квадратных скобках `[...]` — заглушки, которые надо заполнить до запуска.
- **Шрифт.** Onest грузится с Google Fonts только в прототипе; в MODX — локальный woff2.
- **Цвета.** В SCSS остались несколько полупрозрачных `rgb(...)` (затемнение, линии на тёмном фоне) — вынести в токены `overlay-*` при натяжке.
- **URL.** Прототип отдаёт адреса со слэшем на конце (так делает Eleventy). В MODX остаются адреса без слэша, как на текущем сайте; в `redirects.nginx.conf` цели уже без слэша.
- **Сделано меньше, чем в спецификации.** Карусель — на scroll-snap вместо Swiper (меньше JS, тот же результат). Сервисные услуги на главной — сетка, а не карусель.
- **Git.** Проект не в репозитории, коммитов по экранам нет.
